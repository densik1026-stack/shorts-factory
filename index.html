쇼츠공장 (Shorts Factory)

쇼츠공장은 개인이 자신의 PC에서만 사용하는 영상 제작·업로드 보조 프로그램입니다. 본인 소유의 YouTube 채널에 영상을 업로드하고, 업로드한 영상의 상태를 확인하는 데에만 YouTube Data API를 사용합니다.

일반 사용자에게 배포하거나 외부에 제공하는 서비스가 아닙니다.

개인정보처리방침 (Privacy Policy)

Shorts Factory is a personal tool that runs only on the owner's own computer. It uses the YouTube Data API solely to upload videos to, and check the status of videos on, the owner's own YouTube channels. It is not offered to the public.
